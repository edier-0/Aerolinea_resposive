# Proyecto Flynova

Una maqueta responsiva para una aerolínea llamada Flynova, construida con HTML y CSS. El proyecto incluye varias páginas de navegación para búsqueda de vuelos, reserva de paquetes, servicios de equipaje, mascotas y más.

## Estructura del proyecto

- `index.html`: página principal con formulario de búsqueda y enlaces a secciones principales.
- `HTML/`: páginas internas del sitio.
  - `busqueda_de_vuelos.html`
  - `comida.html`
  - `comfirmar_vuelo.html`
  - `datos_de_pasajeros.html`
  - `equipaje.html`
  - `hoteles.html`
  - `mas_paquetes.html`
  - `mas_vuelos.html`
  - `mascotas.html`
  - `pagar_confirmar_reserva.html`
  - `registro_de_mascota.html`
  - `alquilar_coche.html`
- `CSS/`: hojas de estilo por página y estilos globales.
  - `styles.css`
  - `busqueda_de_vuelos.css`
  - `comida.css`
  - `confirmar_vuelo.css`
  - `datos_de_pasajeros.css`
  - `equipaje.css`
  - `hoteles.css`
  - `mas_paquetes.css`
  - `mas_vuelos.css`
  - `macotas.css`
  - `pagar_confirmar_reserva.css`
  - `registro_de_mascotas.css`
  - `alquilar_coche.css`
- `Assets/`: imágenes, iconos y recursos compartidos.

## Características

- Diseño responsivo para diferentes tamaños de pantalla.
- Navegación a través de páginas de servicios y reservas.
- Formularios de búsqueda y selección de fechas.
- Enfoque visual con banners, tarjetas de oferta y secciones de promoción.

## Uso

1. Abrir `index.html` en el navegador.
2. Navegar entre las páginas dentro de la carpeta `HTML/`.
3. Editar archivos HTML y CSS según sea necesario para personalizar el contenido y el estilo.

## Notas

- No se incluyen scripts JavaScript externos en la versión actual del proyecto.
- Las rutas de los recursos están configuradas para una estructura local de carpetas.
